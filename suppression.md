# Suppression du compte et des données — Skate Rascals

<p class="sr-brand"><a href="index.html" aria-label="Accueil Skate Rascals"><img src="assets/skate-rascals-icon.png" alt="Icône Skate Rascals"></a></p>

Dernière mise à jour : 8 octobre 2026.

Cette page explique comment supprimer les données de **Skate Rascals**, édité par **Développement-Solution — Olivier Pagé**.

## Compte joueur

Skate Rascals **ne crée pas de compte chez l’éditeur** : il n’y a ni identifiant, ni mot de passe, ni profil stocké sur un serveur de l’éditeur.

Si vous êtes connecté aux **services de jeux Google Play**, le jeu utilise votre compte Google Play Jeux pour la sauvegarde dans le cloud, les classements et les succès. Ce compte appartient à Google : vous pouvez supprimer les données de Skate Rascals qu’il contient (voir ci-dessous).

## 1. Supprimer les données de jeu sur le téléphone

La progression (pièces, stages, coupes, histoire, personnages, records, défis, succès, réglages) est enregistrée sur l’appareil. Pour l’effacer :

1. Ouvrez les **Paramètres** du téléphone Android.
2. Allez dans **Applications**, puis **Skate Rascals**.
3. Touchez **Stockage** puis **Effacer les données** (ou **Vider le stockage**).

Désinstaller le jeu supprime aussi ces données. Les intitulés peuvent varier selon le téléphone.

**Attention :** si vous êtes connecté à Google Play Jeux, la sauvegarde dans le cloud reste dans votre compte et la progression revient au prochain lancement. Pour tout effacer, faites aussi l’étape 2.

## 2. Supprimer la sauvegarde, les scores et les succès Google Play Jeux

1. Ouvrez l’application **Google Play Jeux** (ou, selon le téléphone, **Paramètres → Google → Jeux**).
2. Ouvrez les **paramètres** de votre profil.
3. Choisissez **Supprimer le compte Play Jeux et les données**, puis, dans **Supprimer les données d’un jeu**, sélectionnez **Skate Rascals**.

Cela supprime la sauvegarde cloud, vos scores dans les classements et vos succès pour ce jeu. Vous pouvez aussi supprimer tout votre profil Play Jeux depuis le même écran. La suppression est effectuée par Google, selon ses propres délais.

## 3. Publicité

Le jeu n’enregistre pas de données publicitaires chez l’éditeur. Pour modifier votre consentement, utilisez **Paramètres → Gérer mes choix de pubs** dans le jeu. Pour supprimer ou réinitialiser l’identifiant publicitaire de votre appareil, allez dans les paramètres Android (**Google → Annonces**, ou **Confidentialité → Annonces** selon les téléphones).

## 4. Demander la suppression des données détenues par l’éditeur

Si vous avez écrit à l’assistance, vous pouvez demander la suppression de vos échanges et de votre adresse e-mail :

[Demander la suppression de mes données](mailto:developpement.solution@gmail.com?subject=Skate%20Rascals%20-%20Suppression%20de%20donn%C3%A9es&body=Bonjour%2C%0A%0AJe%20demande%20la%20suppression%20de%20mes%20donn%C3%A9es%20li%C3%A9es%20%C3%A0%20Skate%20Rascals.%0AAdresse%20e-mail%20utilis%C3%A9e%20pour%20contacter%20l%E2%80%99assistance%20%3A%20%0A)

- **Données supprimées :** vos messages, pièces jointes et votre adresse e-mail.
- **Délai :** au plus 30 jours après la réception de votre demande. Une confirmation vous est envoyée.
- **Conservation éventuelle :** uniquement ce qu’une obligation légale ou un litige en cours impose de garder, et seulement pendant la durée nécessaire.

## Si un compte est ajouté plus tard

Si une future version ajoute un compte joueur chez l’éditeur (par exemple pour le multijoueur en ligne), le jeu proposera la suppression du compte directement dans l’application, et cette page décrira la procédure, les données supprimées, les délais et les éventuelles conservations.

Plus d’informations : [politique de confidentialité](confidentialite.html).
